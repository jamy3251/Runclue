방문하자, 풀자, 벌자.

앱에서 클루를 발견하고, 만들고, 참여하는 흐름을 웹에서도 바로 확인할 수 있게 구성했습니다. 운영자는 웹 관리자 화면에서 새 클루를 승인합니다.

RUNCLUE 로그인 / 회원가입

데모로 보기 버튼은 DB 권한 없이 화면 흐름만 확인합니다.

발견 승인된 클루를 앱 홈처럼 카드와 상태로 탐색합니다.
만들기 클루를 생성하면 기본 상태가 승인 대기가 됩니다.
참여 승인된 클루만 참여 가능하고 정원과 중복 참여를 확인합니다.
승인 관리자는 대기 클루를 승인하거나 반려합니다.

앱 흐름을 웹으로 그대로 연결

  1. 01랜딩 + 인증서비스 소개와 로그인/회원가입을 첫 화면에서 처리
  2. 02클루 발견로그인 후 승인된 클루를 탐색
  3. 03클루 만들기생성 즉시 승인 대기로 전환
  4. 04관리자 승인승인된 클루만 참여 화면에 노출
